All numbers come from the simulator in this repository, not from flight tests. Rates show 95% Wilson intervals and means show 95% Student-t intervals. Overlapping intervals are not evidence of a difference.

Run your own batches

Monte Carlo batches run hundreds of simulated minutes, so they run on your own machine rather than in the browser. Use the live simulator for single runs. To reproduce or extend these tables locally:

PYTHONPATH=src python -m mpuav.experiments --seeds 15 --first-seed 700
