Swarms · Blender + MATLAB

Swarm formation flight show

A 64-second night show for 102 quadcopters: take-off, X formation, star, DNA spiral, heart and a “HOLY HORNET” letter formation, then a landing in a circle. Each formation change uses optimal (Hungarian) assignment with synchronised straight-line moves.

  • 102 drones
  • 9 acts
  • 0.94 m closest pass
Planning · Blender + Python

Multi-UAV path planning with Grey Wolf Optimiser

Three UAVs plan routes past 11 obstacles. A pack of 100 candidate paths per UAV converges over 50 iterations, then the best path is flown with attitude worked out from the trajectory. The run reports path length, obstacle clearance and UAV separation.

  • 3 UAVs
  • 11 obstacles
  • 50 iterations

Control · MATLAB

Quadcopter control in 1D, 2D and 3D

PID control step by step: hover and altitude steps in 1D, line and sine paths in the plane, then line, helix and minimum-snap (7th-order polynomial) trajectories in 3D.

Control · MATLAB

LQR control

A linear-quadratic regulator built from a linearised state-space model. The gain trades tracking error against control effort while the drone follows a desired trajectory.

Control · Simulink

PID vs LQR in Simulink

The same quadcopter flown with PID loops for throttle, roll, pitch and yaw and with an LQR controller, so the two can be compared side by side.

Control · MATLAB

Model predictive control

MPC predicts a short horizon ahead and picks the best inputs, re-solving every step while the drone flies a circle. A second version pairs MPC on an LPV model with feedback linearisation.

Control · MATLAB

Nonlinear MPC

Nonlinear model predictive control on the full quadrotor model, tracking a stored reference trajectory, written up in a report and presentation.

Control · MATLAB + Simulink

Backstepping control

A step-by-step Lyapunov design: the position, velocity and attitude loops are each stabilised in turn, tested on fixed and variable trajectories.

Control · MATLAB

Feedback linearisation

Cancels the quadcopter’s nonlinear dynamics so the outer loop sees a simple linear system, which ordinary linear control can then track.

Control · MATLAB + Simulink

Sliding mode control

Drives the tracking error onto a sliding surface and keeps it there, for robust control under disturbances. Results are compared with PID, LQR, backstepping, feedback linearisation and MRAC.

Control · Simulink

Adaptive fuzzy sliding-mode control

Adaptive nonlinear control that combines fuzzy logic with non-singular terminal sliding mode (NTSMC). The fuzzy rules tune the controller as it flies, so it copes with model errors and disturbances.

Control · Simulink

Fuzzy control with obstacle avoidance

A 6-DOF quadcopter flown by fuzzy inference systems for attitude, altitude and yaw, plus a fuzzy rule set that steers round obstacles.

Autonomy · MATLAB

3D SLAM with an EKF

The UAV maps landmarks while estimating its own position with an extended Kalman filter, with known and unknown landmarks. It flies with differential flatness and an LQR trajectory controller.

Q-learning flight
